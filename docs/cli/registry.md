# CLI: registry

`smartrain registry` manages run artifacts and the `models/` catalog in the workspace.

## Subcommands

- `runs-list`
- `runs-info`
- `runs-metrics`
- `models-add`
- `models-list`
- `models-info`
- `models-remove`

## Examples

```bash
smartrain registry runs-list
smartrain registry runs-info 3
smartrain registry models-add 3
smartrain registry models-list
```
