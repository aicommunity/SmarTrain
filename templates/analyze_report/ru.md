<!-- BLOCK: NARR_PERF_NOT_COLLECTED -->
Если в таблицах производительности PT-строк отображается «нет данных», это значит, что для соответствующих артефактов не собран `perf_*.json` при тестировании модели. Запустите `smartrain model test --collect-performance --run <путь>` для каждого run. Inference benchmark из `analyze all` (рисунок сравнения скорости, `benchmark.csv`) измеряет только PT на CPU и не заполняет performance-таблицы форматов.
